第一步：將工具加入手機主畫面（如同 APP 隨點即開）

微工具無需透過 App Store 下載安裝，請使用手機瀏覽器開啟專屬網址，依照下列步驟即可建立桌面捷徑：

iPhone (Safari 瀏覽器)
  1. 使用 Safari 開啟工具網址
  2. 點擊瀏覽器下方正中央的「分享」圖示
  3. 向下滑動點選「加入主畫面」
  4. 點擊右上角「新增」，完成建立捷徑
Android (Chrome 瀏覽器)
  1. 使用 Chrome 開啟工具網址
  2. 點擊右上角「三個圓點」選單
  3. 點選「加到主畫面」或「安裝應用程式」
  4. 確認新增，即可在手機桌面找到圖示
01. IG 限動空檔生圖器 (studio_slot.html) 操作方式

1. 顧客視角與店長管理切換：網頁開啟時預設為顧客查詢畫面，點擊右上角「店長生圖管理」並輸入 PIN 碼（預設 8888）即可解鎖排程控制台。

2. 設定營業時間與公休：調整切割間隔（15/30/60 分鐘）、設定每日起迄時段，並勾選固定公休日，系統將自動過濾無法預約的時間。

3. 日期區間與時段釋出：選擇開始與結束日期，點擊下方綠色時段按鈕切換開放狀態，確認無誤後點選「一鍵下載 9:16 IG 限動美圖」即可直接轉發至社群限時動態。

02. 極簡快速收銀小幫手 (pos.html) 操作方式

1. 顧客快速帶入：輸入顧客手機號碼，若為曾消費過的顧客，系統將秒自動帶入姓名與 LINE 暱稱；若顧客更換稱呼，送單時將自動更新覆寫。

2. 點選開單：點擊現場施作項目與加購項目，下方即時顯示應收金額，點擊「確認收銀開單」即可記錄至本地流水帳並更新今日與本月營收指標。

3. 新增自訂品項：點擊右上角「項目設定」，可隨時依現場營運狀況新增或調整服務名稱與收費金額。

03. 美業通用服務報價試算器 (quote.html) 操作方式

1. 頂部直式輪播說明圖：上方支援多張 9:16 活動圖片自動輪播，圖片若非標準直式尺寸，系統會自動以背景高斯模糊填補，呈現精緻視覺效果。

2. 自主試算與回傳：將網址置於官方 LINE 圖文選單或 IG 主頁，客人自行勾選基礎項目、護理加購與設計指數後，點擊「複製報價明細」即可格式化貼入官方 LINE 完成預約。

04. VIP 數位會員存摺 (loyalty.html) 操作方式

1. 會員查詢：顧客出示手機輸入號碼，立即展開專屬黑灰燙金數位卡面，同步檢視集點章、儲值餘額與包卡堂數。

2. 店長現場蓋章與核銷：下方管理按鈕受 PIN 碼保護（預設 8888），輸入密碼後可直接進行「+1 點蓋章」、「扣除儲值金」或「核銷包卡 1 堂」。

05. LINE 防放鳥推播排程 (reminder.gs) 設定方式

1. 試算表準備：在 Google 試算表中建立「預約名冊」工作表，欄位依序包含姓名、日期、時間、項目、顧客 LINE UID 與發送狀態。

2. 部署 Apps Script：點選「擴充功能 > Apps Script」，貼上提供的 `reminder.gs` 程式碼，並在頂端變數填入您的 LINE Messaging API Token。

3. 設定排程觸發器：點擊左側時鐘圖示（觸發條件），新增一個每日定時觸發器（建議設定在每晚 20:00 至 21:00 之間），系統即會自動針對明日預約客發送出席提醒。

06. 全日排程總覽與席位防撞 (overview.html) 操作方式

1. 專員代號化與雙檢視切換：上方提供日期橫排按鈕快速切換查看，可選擇「滑動檢視」或「全店同屏」模式掌握各專員全天空檔。

2. 快速插單與防遮擋算法：點擊任何專員的空白時段格子，輸入手機帶入顧客資料即可快速開單；若為 Group A（等待期允許插單）項目，重疊時段自動分欄並排展示，並受到店內設備容量上限保護。

07. 數位定型化契約與 Resend 電子存證 (contract.html) 操作方式

1. 顧客簽署：由顧客填寫姓名、電話與 Email，閱讀完定型化合約條款後，在虛線簽名框內以手指親筆手寫簽名。

2. 電子存證副本自動寄發：點擊確認送出後，系統自動將簽名圖檔封裝，並透過 Resend API 將包含店名、完整條款、簽名圖與時間戳記的正式存證信件寄發至顧客信箱。

常見問題與技術支援 FAQ
Q1：更換手機或清除瀏覽器紀錄，資料會遺失嗎？

微工具的顧客小資料庫與設定預設保存在手機本地儲存區（LocalStorage），若更換手機，可透過整合管理中心（tools-admin.html）匯出或與 Supabase 雲端資料庫同步保存。

Q2：店長預設 PIN 碼可以修改嗎？忘記密碼怎麼辦？

所有工具預設 PIN 碼均為 8888，在各工具管理面板中皆可直接點擊「改 PIN 碼」重設。若忘記密碼，可聯繫官方客服提供店家名稱由技術人員為您重設。

Q3：未來想改用完整版預約系統，流程如何銜接？

隨時可洽詢官方客服了解「美業沙龍 ＆ 寵物美容住宿旗艦系統」，專員將協助您將現有顧客名冊與服務項目無縫匯入旗艦系統。
